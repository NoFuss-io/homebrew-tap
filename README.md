# NoFuss-io Tap

## How do I install these formulae?

`brew install nofuss-io/tap/<formula>`

Or `brew tap nofuss-io/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nofuss-io/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
